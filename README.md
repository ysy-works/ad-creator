# ad-creator
# AI 기반 카페 감성 이미지 생성 서비스

## 서비스 개요

본 서비스는 카페 소상공인을 위한 AI 기반 이미지 생성 서비스입니다.  
사용자가 직접 촬영한 메뉴 사진을 업로드하면, AI가 음료나 디저트의 특징을 참고하여 인스타그램 피드에 어울리는 감성적인 이미지를 생성합니다.

복잡한 프롬프트를 구상하지 않고도, 스마트폰으로 평범하게 촬영한 메뉴 사진을
자연광, 우드톤, 화이트 뉴트럴, 포인트 컬러 등 선택한 콘셉트에 맞는 홍보용 이미지로 새롭게 생성할 수 있습니다.

또한 단순히 이미지 한 장만 제공하는 것이 아니라, 사장님이 바로 SNS에 업로드할 수 있도록 **피드 완성본**을 함께 제공합니다.  
생성된 이미지와 함께 인스타그램 캡션, 해시태그, 스토리용 짧은 문구 등을 자동으로 제안하여 콘텐츠 제작부터 업로드 준비까지의 과정을 줄이는 것이 목표입니다.

## 주요 기능

### 1.  AI 이미지 생성

사용자가 메뉴 사진을 업로드하면 AI가 메뉴의 종류와 특징을 참고하여 인스타그램 피드용 이미지를 생성합니다.

- 음료 및 디저트 사진 업로드
- 선택한 이미지 콘셉트 반영
- 배경과 분위기를 포함한 새로운 홍보 이미지 생성
- 인스타그램 피드용 4:5비율 이미지 제공

### 2. 이미지 콘셉트 선택

사용자는 원하는 분위기의 이미지 콘셉트를 선택할 수 있습니다.

예시 콘셉트:

- 화이트 뉴트럴
- 우드톤
- 대비 강조 포인트 컬러

이를 통해 사용자는 직접 긴 프롬프트를 작성하지 않아도 원하는 이미지 분위기를 선택할 수 있습니다.

### 3. 피드 완성본 텍스트 생성

이미지 생성 결과와 함께 SNS 업로드에 필요한 텍스트 콘텐츠를 함께 제공합니다.

제공 항목:

- 인스타그램 피드 캡션
- 해시태그 추천
- 스토리용 짧은 홍보 문구
- 신메뉴 또는 이벤트용 소개 문구

이를 통해 사용자는 생성된 이미지를 저장한 뒤, 별도의 문구 작성 과정 없이 바로 SNS에 활용할 수 있습니다.

## 서비스 목표

카페 사장님들은 신메뉴, 시즌 메뉴, 이벤트 소식 등을 꾸준히 홍보해야 하지만, 매번 사진을 예쁘게 촬영하고 문구를 작성하는 데 부담을 느낄 수 있습니다.  
본 서비스는 이러한 반복적인 홍보 콘텐츠 제작 과정을 줄이고, 소상공인이 더 쉽고 빠르게 인스타그램 콘텐츠를 제작할 수 있도록 돕는 것을 목표로 합니다.

## 기대 효과

- 카페 메뉴 홍보 이미지 제작 시간 단축
- 프롬프트 작성 없이 레퍼런스 기반 쉬운 이미지 생성 경험 제공
- SNS 업로드에 필요한 이미지와 문구를 한 번에 제공
- 소상공인의 반복적인 홍보 업무 부담 완화
- 인스타그램 피드에 어울리는 감성적인 콘텐츠 제작 지원
